Formula corner

Keep these useful relationships close while solving problems. Always check the conditions and units.

Quadratic Equation

For ax² + bx + c = 0, where a ≠ 0

x = (−b ± √(b² − 4ac)) / 2aQuadratic formula
📈

Arithmetic Progression

First term a, common difference d

aₙ = a + (n − 1)dnth term
Sₙ = n/2 [2a + (n − 1)d]Sum of n terms
⚡

Electricity

Basic relationships for simple circuits

V = IROhm’s law
P = VI = I²R = V²/RElectric power (for an ohmic resistor)
🔍

Magnification

For spherical mirrors using the standard sign convention

m = hᵢ / hₒ = −v/uMirror magnification
🧮

Probability

For equally likely outcomes

P(E) = favourable outcomes / total outcomesProbability of event E
📏

Distance Formula

Between points (x₁, y₁) and (x₂, y₂)

d = √[(x₂−x₁)² + (y₂−y₁)²]Coordinate geometry
